```bash
cd ~/python_learning/major_project_2
# 终端 1：后端
```

## 八、异常优先级验证

异常优先级：**401 > 403 > 400 > 429 > 409 > 404 > 500**（接口返回 `{code, msg, data}`，code 与 HTTP 状态码一致）。

| # | 场景 | 预期 |
|---|------|------|
| 8.1 | 未登录直接调 `GET /api/problems/` | 401 |
| 8.2 | 普通用户调 `DELETE /api/problems/P1001` | 403 |
| 8.3 | 提交缺参数 / 非法 JSON | 400 |
| 8.4 | 1 分钟同题提交超 3 次 | 429 |
| 8.5 | 新增题目 id 已存在 | 409 |
| 8.6 | 查询不存在的题目 / 提交 | 404 |
| 8.7 | 普通用户查别人提交 | 403 |
