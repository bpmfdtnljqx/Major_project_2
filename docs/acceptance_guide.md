# OJ 系统验收操作指南

> 本指南带你从启动到结束，手动验证系统的全部功能。
> 系统账号：管理员 `admin` / `admintestpassword`。

## 一、启动系统

在 WSL 中打开两个终端，都进入项目目录：

```bash
cd ~/python_learning/major_project_2
```

**终端 1 —— 启动后端（FastAPI）：**

```bash
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
```

**终端 2 —— 启动前端（Streamlit）：**

```bash
.venv/bin/streamlit run frontend/app.py
```

然后浏览器打开 **http://localhost:8501**。

> 说明：前端左侧是页面导航（登录页 / Users / Problems / Submissions / AI）。AI 命题页面只有管理员可见。

---

## 二、用户管理（Users）

| 操作 | 步骤 | 预期 |
|------|------|------|
| 注册 | 首页「注册」标签，输入用户名 `alice`、密码 `pw123` | 提示注册成功 |
| 登录 | 切到「登录」，用 `alice/pw123` 登录 | 登录成功 |
| 我的信息 | 进入「Users」页面 | 显示 alice 的信息、提交数 0 |
| 管理员功能 | 用 `admin/admintestpassword` 登录后进「Users」 | 能看到用户列表、改角色、创建管理员 |

**验证点**：普通用户看不到「创建管理员」和「用户列表」；`admin` 能改别人角色为 `banned`，被 ban 后该用户再登录会提示 403。

---

## 三、题目管理（Problems）

| 操作 | 步骤 | 预期 |
|------|------|------|
| 查看题目 | 进「Problems」，默认有 `P1001`（A+B Problem） | 下拉能选题目看详情 |
| 添加题目 | 「新增题目」填必填字段，样例/测试点用 JSON 填 | 提示新增成功 |
| 编辑题目 | 「编辑题目」选一个题，改标题后保存 | 提示已保存 |
| 删除题目 | 详情里点「删除此题」（仅 admin 可见） | 提示已删除 |

**验证点**：普通用户看不到「删除」按钮；`id` 重复的新增会提示失败。

---

## 四、评测提交（Submissions）

| 操作 | 步骤 | 预期 |
|------|------|------|
| 提交代码 | 进「Submissions」，选题目 `P1001`、语言 `python`，粘贴下面代码，点提交 | 提示提交成功 |
| 查看结果 | 下方「我的提交记录」选中刚才的提交，点「刷新状态」 | 状态 success、得分 10、测试点明细 AC |

**测试代码（A+B）：**

```python
import sys
a, b = map(int, sys.stdin.read().split())
print(a + b)
```

**验证点**：提交一个错误代码（如 `print(1)`），结果会是 WA；提交死循环代码会 TLE；提交语法错误会 CE（编译型语言）。

---

## 五、AI 智能命题（仅管理员）

| 操作 | 步骤 | 预期 |
|------|------|------|
| 生成题目 | 用 `admin` 登录，进「AI」页面，输入需求如「生成一道判断闰年的题」，点生成 | 状态 running → completed |
| 查看结果 | 等几秒点「刷新状态」 | 显示生成的题目 + Token 用量 |
| 确认入库 | 进「Problems」页面 | 能看到刚生成的 `ai_xxx` 题目 |

**验证点**：普通用户 `alice` 登录后，左侧**看不到** AI 页面。

---

## 六、评测日志与审计（管理员）

| 操作 | 步骤 | 预期 |
|------|------|------|
| 日志可见性 | admin 在题目详情可设置「日志公开」 | 设置后其他用户能看该题的评测日志 |
| 访问审计 | 通过 API 或前端查看评测日志后，admin 可查询审计记录 | 记录了谁在何时访问了哪道题、结果如何 |

---

## 七、系统重置（管理员）

系统重置接口 `POST /api/reset/` 用于清空测试数据、恢复初始环境。可在浏览器开发者工具或 curl 中调用：

```bash
# 先登录拿 cookie，再用 admin 身份重置
curl -X POST http://127.0.0.1:8000/api/reset/ -H "Cookie: session=<登录后的session>"
```

**预期**：清空所有测试用户/题目/提交，退出登录，恢复初始管理员 `admin`。
